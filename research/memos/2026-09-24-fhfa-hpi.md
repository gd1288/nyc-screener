# FHFA House Price Index (HPI)

**Recommendation: recommend.**

## What it is
FHFA's repeat-sales home price index, built from tens of millions of conforming-mortgage
transactions. Published quarterly (some variants monthly) at national, census-division, state,
MSA, county, ZIP, and census-tract levels. Bulk ASCII/CSV downloads at
https://www.fhfa.gov/data/hpi/datasets, no login, no API key. As a work of the federal government,
it's public domain — no redistribution or commercial-use restriction of any kind.

## Why it could help
`backend/app/scoring/backtest.py` currently checks whether the Growth Score predicts future condo
appreciation using NYC-specific data (DOF condo sales, Zillow ZHVI). The ZHVI feed comes from
`zillow_research.py`, which explicitly filters to `NYC_COUNTIES` even though Zillow's underlying
ZHVI/ZORI data is national — so the NYC-only limitation is this codebase's adapter, not a gap in
Zillow's coverage. Grepped `backend/` for any existing FHFA usage: none found, so this is a genuinely
new source, not a duplicate. FHFA HPI's real advantage over simply widening the Zillow adapter's
filter is licensing (public domain vs. Zillow's research-data terms) and methodology (repeat-sales
controls for property mix better than a median), plus county/tract granularity. It's also literally
the benchmark `research-sources/SKILL.md` names for the not-yet-built `evaluate_series.py` tool, so
adding it now sets up that evaluation infrastructure for every future candidate, not just this one.

## Evaluation
- **Cost**: free. **Auth**: none. **Rate limit**: n/a — static quarterly file downloads.
- **Granularity**: county/MSA level covers essentially the whole country (some very small/rural
  counties may lack enough transaction volume for a stable index — normal for repeat-sales indices,
  not a defect of this source).
- **History**: back to 1975 for national/state; MSA and county series start later in some markets
  but are still typically decades deep — comfortably enough for the kind of backtest this project
  already runs.
- **License**: cleanest of the three candidates evaluated this run — public-domain government data,
  zero redistribution risk. **Caveat**: fhfa.gov was not directly reachable from this session
  (egress to that domain was blocked in this environment), so this is from search-engine summaries
  of FHFA's own pages, not a direct read — confirm before implementing.
- **Condo coverage**: UNVERIFIED. Whether the standard HPI variant includes condo transactions or
  only single-family properties wasn't confirmed this pass, and that matters a lot for a condo
  screener. Check this first, before anything else, when evaluating this candidate further.
- **Format**: fixed-width/ASCII rather than JSON, so the adapter needs a small parser. Ordinary
  adapter work, same shape as the existing DOF/Census adapters, not a blocker.
- No `evaluate_series.py` correlation run — the tool doesn't exist yet in this repo. Worth noting
  that FHFA HPI would likely become the *reference* series that tool checks other candidates
  against, rather than something evaluated against itself.

## Bottom line
Strongest candidate of the three evaluated this run: genuinely national, no auth, no rate limit,
uncomplicated license, decades of history, and it closes a real structural gap (a
non-NYC-specific appreciation benchmark) rather than just adding one more metric.
