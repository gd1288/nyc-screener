# BLS Local Area Unemployment Statistics (LAUS)

**Recommendation: recommend-with-caveat**

## What it is
BLS's monthly county/metro/city unemployment-rate series. Source: https://www.bls.gov/lau/ , via the
public BLS API v2 (JSON, series IDs like `LAUCN360610000000003` for New York County) or bulk flat
files. A free API key (bls.gov/developers) raises the query-rate limit, the same pattern the project
already uses for `census_api_key`.

## Why it could help
The only local economic signal currently feeding the Growth Score is `census_acs.py`'s 5-year ACS
estimates (income, education, age, tenure) — updated twice a year and comparing releases 10 years
apart. There's no timely employment indicator, even though local job growth is a standard leading
signal for housing demand and rent growth. LAUS would add a monthly-frequency complement.

## Evaluation
- **Coverage/granularity**: national; county-level (NYC's 5 boroughs = LAUS's 5 counties, a clean
  1:1 match to the county list `census_acs.py` already uses). Coarser than tract/NTA — one number
  per borough, not per neighborhood. For a single-county metro elsewhere this would be one number
  for the whole metro.
- **Update frequency**: monthly (~1 month publication lag), annual benchmark revisions.
- **History**: **not independently verified this run** — no exact start year turned up in search
  results; LAUS county series are commonly cited elsewhere as going back to the 1990s, but confirm
  on bls.gov before relying on it for a multi-decade backtest.
- **Cost**: free; BLS asks that bulk pulls across thousands of counties use a registered key, but
  this project only ever needs a handful of counties per metro, so that's a non-issue.
- **License**: BLS is a federal agency (Dept. of Labor), so public domain is the expected default,
  and a third-party source (an MCP server's own dataset description) explicitly labels it public
  domain — but this was **not confirmed on BLS's own terms page** this run. No login required for
  the public data per search results; the optional key is purely for higher rate limits.
- **Correlation**: not computed (`evaluate_series.py` doesn't exist yet). The more plausible
  predictor is the *trend* in unemployment rate, not the level — worth checking once that tool
  exists, rather than assuming it helps.

## Recommendation
Worth adding as a `neighborhood`-kind source keyed by county, joined the same way `census_acs.py`
already groups by county. The caveat is granularity: at the county level this is a borough-level
signal, not a neighborhood-level one, so it should feed a citywide/boro "local labor market" factor
rather than be presented as varying within a borough — and it should be checked for actual
predictive lift (via `evaluate_series.py`, once built) before being weighted into the Growth Score.
**Before implementing**, confirm the series start year and the public-domain claim directly on
bls.gov, since neither was independently verified this run.
